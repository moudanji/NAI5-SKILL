功能 ：除了基础的写提示词之外，他还能够一次性。生成带有分镜的复杂漫画提示词，以及复杂构图，反推能力
特色：这个SKILL写的提示词，除非特殊要求，否则，模型认识的版权角色不会带有眼睛，头发，衣服相关的提示词内容。

1.漫画功能：默认生成从右向左的漫画，只有当你  要求生成从左往右读的漫画时，才会生成从左往右的漫画
你不仅需要复制粘贴这些提示词，还需要依照AI给出的指令，将角色一个一个摆放到对应的位置上
例如：我要制作原神的芙宁娜，荧，胡桃枕头大战的5格漫画，其中有一格是三人同屏互动。请帮我设计剧情和分镜     

2.复杂构图：只有当你输入 复杂构图 的时候，AI才会自动帮你想一个比较复杂的构图
例如，输入“  复杂构图，小女孩在卧室玩玩具”，就能生成相对复杂的构图

3.多人图：它能够生成多人图的提示词，并且描述这些角色的互动关系。

4.反推：当你上传图片，并说出反推的时候，才会反推。不仅能反推图片，还能反推漫画和多人图片。


使用方式，把  nai5-prompt-expert 这个文件夹导入一些AI的“导入skill”功能，就能用了。有些AI可能需要你把nai5-prompt-expert这个文件夹压缩之后再导入
如果你像我一样之前从来没有用过SKILL，可以问AI，如何导入和使用skill.
有的AI不支持导入SKILL，比如deepseek网页版

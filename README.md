功能 ：除了基础的写提示词之外，他还能够一次性。生成带有分镜的复杂漫画提示词，以及复杂构图，反推能力
特色：这个SKILL写的提示词，除非特殊要求，否则，模型认识的版权角色不会带有眼睛，头发，衣服相关的提示词内容。

1.漫画功能：默认生成从右向左的漫画，只有当你  要求生成从左往右读的漫画时，才会生成从左往右的漫画
你不仅需要复制粘贴这些提示词，还需要依照AI给出的指令，将角色一个一个摆放到对应的位置上
例如：我要制作原神的芙宁娜，荧，胡桃枕头大战的5格漫画，其中有一格是三人同屏互动。请帮我设计剧情和分镜
